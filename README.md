# Raj Chowk

Production-oriented Hindi news, opinion, civic-polling, public-question and promise-tracking platform built with Next.js 15 and AWS Amplify Gen 2.

## Included features

- Published news and opinion with category/tag discovery, sources, redirects, comments, RSS and news sitemap
- Public polls with authenticated, idempotent voting
- Audience questions and authenticated upvotes
- Government promise tracker and live-event registration
- Search and double-opt-in newsletter flows
- Cognito sign-up, confirmation, sign-in and account management
- Editor/admin publishing and moderation surfaces with group authorization
- S3 media, DynamoDB durability controls, rate limiting, audit logs and CloudWatch alarms

## Local setup

Requirements: Node `22.22.2`, npm `10.9+`, an AWS profile, and Amplify sandbox access.

```bash
npm ci
cp .env.example .env.local
npx ampx sandbox secret set RATE_LIMIT_IP_SALT
npx ampx sandbox secret set NEWSLETTER_TOKEN_SECRET
npm run sandbox:once
npm run dev
```

`amplify_outputs.json` is generated by Amplify and intentionally ignored by Git.

## Verification

```bash
npm run verify             # format, lint, types, 640 unit/component tests, build
npm run test:integration   # live sandbox authorization and data behavior
npm run e2e:install        # one-time Playwright browser install
npm run e2e:mocked         # routes, forms, accessibility and responsive layout
```

Run `npm run verify:full` after a sandbox is deployed. Integration tests create isolated users and rows and remove them during teardown.

## Amplify deployment

Connect the repository to AWS Amplify Hosting and use the committed `amplify.yml`. The pipeline deploys the backend first, generates `amplify_outputs.json`, runs the frontend quality gates, and publishes the standard `.next` artifact.

Configure the public variables from `.env.example` in the Amplify branch environment. Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS origin without a trailing slash and `NEXT_PUBLIC_ENV=production` on the production branch. Add `RATE_LIMIT_IP_SALT` and `NEWSLETTER_TOKEN_SECRET` as Amplify secrets; never add their values to Git.

See [deployment](docs/deployment.md), [architecture](docs/architecture.md), and the [operations runbook](docs/operations-runbook.md) before the first production release.

## Security note

The dependency override rationale is recorded in `package.json`. The remaining `immutable@3.7.6` advisory is confined to Amplify's development-only schema code-generation chain and is not reachable by application traffic; upgrading it across two major versions is deferred until Amplify supports that dependency safely.
